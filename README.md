# solo-8800002

一个基于 Vite + Vue 3 的纯前端小众业务示例项目，主题是古籍虫蛀修复批次管理。

## 开发

```bash
npm install
npm run dev
```

`vite.config.js` 已显式配置 `server.open = false`，启动开发服务时不会自动打开浏览器。

## 构建

```bash
npm run build
```

## 负责人负载分配

在「任务清单」页提供受控的分配台（`AssignmentConsole.vue`），状态由
`src/composables/useAssignmentStore.js` 模块级单例统一持有：

- **集中呈现**：待分配任务、修复师当前在办量 / 容量、每人可用时段与占用情况。
- **权限控制**：默认「查看者」只读，仅能查看系统建议；切换为「分配员」后才能落单、
  裁定认领与回退（变更操作在 store 内再次校验身份）。
- **落单前阻断**：负责人已停用、修复师满载、时段不在可用范围或已被占用、任务被两人
  同时认领时均不能直接落单，界面给出明确阻断原因与可回退的建议候选；认领冲突须先
  「采用某人」或「释放全部认领」后才能继续。
- **可回退**：落单与认领裁定按操作顺序入栈，可逐步撤销。
- **两处一致**：任务清单（`/tasks`）与修复总览工作台（`/`）共用同一 store，
  负责人统计与任务归属实时一致。
- **历史封存**：状态为 `archived` 的历史任务只读，始终显示 `originalOwnerId`
  对应的原负责人，即使该修复师已停用。
